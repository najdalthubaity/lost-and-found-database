Lost & Found Database System

Project Overview

A database project developed using MySQL to support the organization and management of lost and found item records.

The project demonstrates the application of relational database concepts and SQL in a practical lost-and-found management scenario.

Project Objectives

* Organize information about lost and found items.
* Support structured storage and retrieval of item records.
* Apply database design and SQL concepts to a real-world problem.

Technologies Used

* Database Management System: MySQL
* Query Language: SQL
* Core Concepts: Relational Databases, Database Design, Data Management

Academic Context

Developed as part of my Computer Science coursework at Umm Al-Qura University.
